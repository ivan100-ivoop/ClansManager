
# ClansManager

ClansManager is plugin for minecraft java.
This plugin allow you to create clans with bank also clan chat and clan bank.
ClansManager also have admin commands to easy manager player clans.

# Player Command

- /clan create <clanName> creating a clan
- /clan set <prefix, owner, tp> set your clan prefix or give clan to your frend is not requerd to be clan member also you can set teleport point for your clan.
- /clan tp simply teleporting you to clan teleport point default is where clan are created.
- /clan list allow you to see all clans in server also if you click on your clan will teleport you to clan location not working for another clan if is not your!
- /clan back <deposit, balance, withdraw> allow you and your members to see clan balance also to deposit or withdraw money from it.
- /clan chat <message> if your member use this command them name will be in green but if you send clan message it will be in red.
- /clan lock this command is locking or unlocking commands for your members in clan.
- /clan invite is simply send invite to your frend is for some resone your frend left server or lost internet connection is not problem invite will be in database.
- /clan accept <clanName> if your have pending invites your will see clan names!
- /clan kick <player> with this command your can easy kick some anoing member.
- /clan kickall will kick all members in clan.
- /clan remove allow you to remove clan.
- /clan chest is chest for your clan your and your clan members can store items there.
-/clan leave base only members can use it to leave your clan.


# Admin Command

- /clan admin is master command.
- /clan admin tp <clanName>
- /clan admin remove <clanName>
- /clan admin kick <clanName> <member>
- /clan admin setOwner <clanName> <new Owner Name>
- /clan admin balance <clanName>
- /clan admin take <clanName> <amount>
- /clan admin give <clanName> <amount>
- /clan admin clear <clanName>
- /clan admin spyChat <enable. disable> <clanName>
- /clan admin chest <clanName>
